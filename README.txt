FOR JUNI, ALWAYS - WEBSITE FILES

HOW TO OPEN
1. Unzip juni_apology_website.zip.
2. Open index.html in a browser.

HOW TO ADD YOUR OWN PHOTOS
1. Open the assets/photos folder.
2. Add your own images using these exact filenames:
   juni-photo-1.jpg
   juni-photo-2.jpg
   juni-photo-3.jpg
   juni-photo-4.jpg
   juni-photo-5.jpg
   juni-photo-6.jpg
   juni-photo-7.jpg
   juni-photo-8.jpg
3. Refresh index.html. You can use screenshots, chat memories, selfies, or any images that feel meaningful.
4. To change captions, edit the figcaption text in index.html.

HOW TO CUSTOMISE THE PUZZLE
Open script.js and edit the puzzleQuestions array near the top.
Each question has:
- question: the question shown
- options: the answer buttons
- answer: the correct answer (must match one option)
- hint: the gentle hint shown after a wrong answer

HOW TO EDIT THE LETTER
Open index.html and find the section with id="letter". Edit the paragraphs inside it.

NOTE
This is a static website. It does not upload photos to a server or collect responses.
The Google Fonts import needs an internet connection; system fonts will be used if offline.
